# 프로필 링크 페이지 설계

## 목적과 승인된 방향
사용자가 제공한 참고 이미지처럼 프로필 사진, 이름, 소개글 아래에 여러 링크를 세로로 배치한다. 방문자는 카드 하나를 눌러 원하는 사이트로 이동한다. 사용자는 연한 분홍색 배경, 둥근 흰색 카드, 모바일과 PC 대응 구성을 승인했다.

## 화면
- 한국어 한 페이지로 구성한다.
- 모바일에서는 화면 좌우 여백을 두고, PC에서는 최대 너비 480px의 중앙 정렬 레이아웃을 사용한다.
- 상단에는 원형 프로필 이미지, 이름, 소개글을 표시한다.
- 아래에는 링크 목록을 세로로 배치한다. 각 카드에는 선택적인 썸네일, 제목, 짧은 설명, 이동 표시를 넣는다.
- 긴 제목과 설명은 자연스럽게 줄바꿈한다. 카드 전체를 클릭하거나 키보드로 선택할 수 있다.
- 참고 이미지의 색감과 배치만 활용한다. 이미지 속 인물의 사진, 이름, 상품 설명을 사용자 정보로 복제하지 않는다.

## 콘텐츠 관리
- dist/profile.js 한 파일에서 이름, 소개글, 프로필 이미지 경로와 링크 목록을 수정한다.
- 링크는 title, description, url, image 필드를 사용한다. description과 image는 생략할 수 있다.
- 사용자 사진과 실제 링크가 아직 없으므로 처음에는 기본 아바타와 예시 문구를 표시한다.
- 주소가 없는 예시 카드는 '링크 준비 중' 상태로 표시하며 이동하지 않는다. 임의의 상품이나 타인의 계정으로 연결하지 않는다.
- 설정 파일을 수정한 후 사이트를 다시 배포하면 모든 방문자에게 변경된 내용이 표시된다.
- 관리자 로그인, 데이터베이스와 브라우저 내 편집 기능은 이번 범위에 포함하지 않는다.

## 기술과 파일 구조
외부 프레임워크 없이 HTML, CSS, JavaScript로 구성하는 정적 페이지를 사용한다. 이 방식은 단순한 링크 페이지에 적합하며 설치 단계 없이 정적 호스팅에 올릴 수 있다.
- dist/index.html: 문서 구조, 메타 정보와 기본 콘텐츠 영역.
- dist/styles.css: 참고 이미지 기반 색상, 간격, 카드 디자인, 반응형 스타일과 포커스 표시.
- dist/profile.js: 사용자 프로필과 링크 설정.
- dist/app.js: 설정을 읽어 프로필과 링크 카드를 안전하게 렌더링.
- dist/assets/avatar.svg: 사용자가 사진을 넣기 전 표시할 기본 아바타.
- README.md: 실행, 사진 변경, 링크 추가, 배포 방법.

## 링크와 오류 처리
- 유효한 HTTP 또는 HTTPS 주소만 이동 링크로 사용한다.
- 외부 링크는 새 탭으로 열고 rel='noopener noreferrer'를 설정한다.
- 주소가 없거나 유효하지 않으면 클릭할 수 없는 준비 상태를 표시한다.
- 프로필 이미지가 없거나 불러오지 못하면 기본 아바타를 표시한다.
- 썸네일 로딩 실패 시 카드 레이아웃을 유지하는 기본 표시를 사용한다.
- 설정 문자열은 HTML로 실행하지 않고 텍스트로 표시한다.

## 접근성 및 검증
- 문서 언어를 ko로 설정하고 제목 계층, 설명이 있는 링크와 키보드 포커스를 제공한다.
- 최소 44px의 클릭 영역과 읽기 쉬운 대비를 유지한다.
- 360px 모바일 화면 및 1440px 데스크톱 화면에서 가로 넘침과 카드 정렬을 확인한다.
- 실제 링크 이동, 미설정 주소, 잘못된 주소, 긴 한국어 문구, 이미지 실패와 키보드 조작을 확인한다.
- 브라우저 검증 환경을 사용할 수 없으면 가능한 정적 및 동작 검증을 수행하고 미확인 항목을 전달한다.

## 전달과 게시
작업 공간에 실행 가능한 정적 사이트와 사용 설명서를 제공한다. Sites 게시가 지원되는 경우 새 사이트의 기본 비공개 접근 상태로 게시하고 실제 반환된 주소를 전달한다. 게시 도구나 필수 실행 환경을 사용할 수 없으면 로컬 파일을 전달하고 게시 제한을 명시한다. 누구나 방문 가능한 공개 전환과 도메인 구매는 이 설계 승인에 포함하지 않는다.
